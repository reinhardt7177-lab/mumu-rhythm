# 음표 기사단: 침묵의 성 — 상세 기획 및 구현 계획

작성일: 2026-11-09. 대상: 초등 4~6학년. 이번 납품: 1곡, 4구간 전투, 마왕전, 결과와 3문항 퀴즈까지 완주 가능한 웹 게임.

## 방향과 구조
기존 Vite/TypeScript/Web Audio 판정 엔진을 재사용한다. 다른 엔진으로 옮기는 비용 대신 Canvas 픽셀 아트와 pixelfx 스프라이트를 결합한다. 기존 스튜디오 소스는 유지하고 새 메인 진입점을 제공한다.
PC: 왼쪽 45% 리듬 5레인 / 오른쪽 55% RPG. 모바일: 위쪽 전투 38%, 아래쪽 리듬 62%. 두 화면 모두 음악 시계로 갱신되며 일시정지와 탭 숨김에서 함께 멈춘다.

## 이야기
침묵의 마왕이 왕국의 박자를 빼앗았다. 음표 기사는 숲의 슬라임, 폐허의 유령, 성문의 골렘을 지나 침묵의 성으로 들어간다. 음악의 마지막 주제에서 마왕을 쓰러뜨려 왕국의 소리를 되찾는다.
실패해도 음악은 중단되지 않는다. 곡 종료 후 승리/재도전과 감상 문제를 제공한다.

## 한 판의 흐름
1. 곡/난이도 확인과 시작. 처음 화면에서도 2분할 무대를 미리 볼 수 있다.
2. 4박 카운트인 → 멜로디 노트 입력 → 음표 공격.
3. 진행률 0/24/48/72% 구간에서 적이 순서대로 등장. 앞 적을 쓰러뜨렸어도 다음 구간까지 기다린다.
4. 마지막 28%는 마왕전. 공격 성과에 따라 승리한다. 미입력으로 자동 승리하지 않는다.
5. 수집률/최고 콤보/처치 수 → 음악이론 3문항 → 정답 해설과 다시 연주.

## 입력과 음악
A S D J K 키보드 또는 보이는 바 직접 터치. 쉬움은 보이는 바 수집, 도전은 박자 판정. 긴 바는 음 길이가 끝날 때까지 유지한다.
기존 AudioEngine의 보정된 시계와 RhythmGame을 공유한다. 리듬 결과를 combat.hit에 전달하며 전투 애니메이션이 오디오를 지연시키거나 정지하지 않는다.

## 음악 기반 전투
- 기본: 8분음표 탄환. 입력 성공마다 자동 발사.
- 정확한 박: PERFECT는 강화 음표, 추가 피해.
- 8콤보: 여러 음을 겹친 화음 폭발. pixelfx smite를 음악 마법의 광원으로 재해석한다.
- 홀드 완료: 지속음의 에너지를 긴 음표 꼬리로 표현.
- 방어: MISS는 기사의 하모니 게이지를 감소시킨다. 곡은 이어지고 성공 입력으로 회복된다.
- 과도한 섬광과 화면 흔들림은 금지. reduced-motion에서 흔들림/섬광을 줄인다. 동시에 살아 있는 효과를 제한한다.

## 시각 규칙
원본 픽셀 해상도 480x300 전투, 240x360 리듬. imageSmoothingEnabled=false와 CSS image-rendering:pixelated. 한글은 가독성을 위해 DOM 폰트로 표시한다.
검정/잉크 배경에 민트·금색·산호색을 공격 강조색으로 사용. 적별 실루엣과 배경 색이 구별된다. HUD는 캔버스와 분리해 글자와 입력이 겹치지 않게 한다.

## 음원 정책과 이번 곡
이번 장은 오펜바흐 캉캉의 기존 편집 음원과 분석 채보를 사용한다. Wikimedia Commons 원음 설명 페이지에서 public-domain dedication과 수정/배포 허용 표시를 확인했다.
출처: https://commons.wikimedia.org/wiki/File:Offenbach_-_Orpheus_in_the_Underworld_-_Overture,_Can_Can_section.ogg
녹음 출처 Musopen. 기존 편집 사항은 THIRD_PARTY_ASSETS.md. 작곡의 퍼블릭 도메인과 녹음 권리는 별도로 확인한다.
후속 후보: 같은 조건을 확인한 클래식, 전래 동요 직접 녹음, 명시적 CC0/CC BY 녹음. 무료 청취 링크를 재배포 허가로 간주하지 않는다. 상용 동요 녹음은 별도 허가 없이 포함하지 않는다.

## 학습
첫 곡은 2박자·반복 리듬·강약을 다룬다. 리듬과 공격의 시각 대응을 통해 반복을 체험하고, 종료 후 3문항에서 정답과 이유를 확인한다. 점수와 음악 지식 점수는 구분한다.

## 파일과 검증
- src/quest/combat.ts: 순수 전투 상태·진행 게이트·피해 계산, 단위 테스트.
- src/quest/battlefield.ts: 오리지널 캐릭터/몬스터/맵, 음악 탄환, 실제 pixelfx 시트 재생.
- src/quest/main.ts: 기존 음악 엔진 통합, 2분할 레이아웃, 입력/일시정지/결과/퀴즈.
- src/quest/style.css: 반응형 픽셀 UI.
- public/assets/pixelfx: MIT 라이선스의 렌더링된 시트와 출처.
검증: tsc/Vite 빌드, 전투 순수 테스트, 실제 브라우저 시작/입력/일시정지/모바일, 자동 입력으로 곡 종료와 마왕 처치/퀴즈 확인.

## 확장 경계
이번 판에는 장비상점·계정·과금·무한곡 자동분석·랜덤 던전은 넣지 않는다. 후속 장은 검증된 곡과 전용 시나리오/문제 데이터를 추가하는 방식으로 확장한다.
