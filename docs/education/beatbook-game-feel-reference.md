# 비트북 손맛 비교

비교 대상: [공개 게임](https://namgh1992-alt.github.io/musicbitbook/)과 [공개 소스 스냅샷](https://github.com/namgh1992-alt/musicbitbook/blob/3e5c446fd1b6a64c1577d3487d1aef39915bdd1c/index.html). REA MCP가 연결되어 있지 않아 공개 소스와 Chrome의 정상 플레이를 대조했다. 코드·편곡·채보·스킨은 프로젝트에 가져오지 않았다.

## 확인한 차이

| 항목 | 비트북 | 음표 기사단 로컬 시범 |
| --- | --- | --- |
| 입력음 | 레인 입력 직후 짧은 클릭. 판정과 독립적이며 설정에서 끌 수 있음 | 레인은 먼저 빛나지만 노트 판정이 없으면 타격음도 없음. 구름 점프 롱노트 시작은 예외적으로 별도 반응 |
| 쉬운 채보 | 중심 박과 충분한 간격을 기준으로 주선율의 음을 선별. 항상 마디 첫박만 선택하지는 않음 | 구름 점프 초급은 마디 첫박만, 중급은 베이스 위주 |
| 중·고급 | 선율에서 출발해 실제 저음 반주를 일부 동시 입력으로 추가. 고급은 밀도·레인 충돌을 검사하며 반주 확대 | 구름 점프 고급은 선율과 빈자리 반주를 한 번에 한 입력으로 배치 |
| 입력 설계 | 7키. 손가락 위치와 사용 빈도를 일부 배치 규칙에 반영. 터치에서 레인 간 이동 처리 | 5키와 두 입력 모드. 고급의 절대 음높이 방향은 보존하지만 자주 쓰는 레인이나 동시 입력을 별도로 설계하지 않음 |
| 타격 표현 | 키 반짝임과 판정 파티클이 각각 입력 레인에 붙고 콤보 숫자는 연속 표시 | 입력 강조와 픽셀 효과는 이미 있음. 판정 텍스트와 전투 반응이 있으므로 모두 다시 그릴 필요는 없음 |
| 소리 생성 | 가락과 반주 이벤트에서 신시사이저와 채보를 각각 구성. 템포 변화도 같은 시간 변환 사용 | 녹음·렌더 파일이 재생되고 채보는 별도. 구름 점프 시범은 그 렌더의 작곡 소스에서 이벤트를 추출 |

근거: [레인·채보 718–855행](https://github.com/namgh1992-alt/musicbitbook/blob/3e5c446fd1b6a64c1577d3487d1aef39915bdd1c/index.html#L718-L855), [입력·판정 3343–3429행](https://github.com/namgh1992-alt/musicbitbook/blob/3e5c446fd1b6a64c1577d3487d1aef39915bdd1c/index.html#L3343-L3429), [입력음 3135–3141행](https://github.com/namgh1992-alt/musicbitbook/blob/3e5c446fd1b6a64c1577d3487d1aef39915bdd1c/index.html#L3135-L3141).

## 브라우저 관찰

- 비트북 페이지 HTTP 200. 곡 선택에 67개 카드가 표시됐다. 첫 곡은 작은 별 변주곡이다.
- 첫 곡 카운트인에서 Space를 한 번 입력했다. 점수는 0으로 유지되며 Web Audio 버퍼 재생 시작이 1회 추가됐다. 추가 버퍼 길이는 0.04초였다.
- 로컬 구름 점프 고급, 박 맞추기에서 첫 노트 전에 A를 한 번 눌렀다. 레인에 눌림 상태가 생겼고 점수는 0, 버퍼 시작 횟수는 그대로였다.
- 측정한 것은 소리 예약과 버퍼 길이다. 스피커에서 귀까지의 지연, 사람의 선호, 모바일 실기기 응답을 측정한 것은 아니다.

## 독자 구현 순서

1. **입력과 명중을 분리한다.** 잘 맞아야만 들리는 반응 외에, 매 누름의 작고 짧은 클릭을 별도 음량 또는 끄기 옵션으로 제공한다. 성공했을 때만 판정선 충격과 음높이 반응을 더한다. 롱노트는 시작과 끝을 구분한다. 원곡이나 게임 시계를 끊지 않는다.
2. **첫박은 도입, 쉬운 본편은 가락.** 구름 점프의 짧은 첫박 연습 뒤에는 묻고 답하는 가락의 첫 음, 방향이 바뀌는 음, 끝음을 실제 시점대로 남긴다. 중급에는 프레이즈 사이에 들리는 베이스 대답을 더한다.
3. **5키에서 두 손의 합주를 만든다.** 고급의 실제 가락·베이스 동시 시작점 중 음악적으로 눈에 띄는 몇 군데만 두 노트로 선택한다. 키보드와 모바일 두 손가락, 롱노트 충돌 및 보스 진행을 같이 검증한다.

먼저 같은 곡과 채보에서 입력음만 바꿔 A/B로 들어 본 뒤, 가락 중심 채보를 별도로 비교한다. 여러 변경을 한 번에 넣어 무엇이 좋아졌는지 흐리지 않는다.
