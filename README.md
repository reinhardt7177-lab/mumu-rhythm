# MUMU 리듬 스튜디오

현재 첫 화면은 **전체 화면 음악 라이브러리**입니다. 과거·현재·미래·판타지 세계와 14곡을 선택하고, 짧은 곡 소개를 읽은 뒤 5레인 낙하바와 자동 전투를 플레이합니다. 세계마다 주인공 1명과 몬스터 4종을 전용 이미지 에셋으로 사용하며, 결과에서는 선택한 곡의 감상 문제 3개를 풉니다. 기존 스튜디오는 `/studio.html`에 별도로 남아 있습니다.

최신 전투 버전은 네 세계 모두 전용 8자세 캐릭터와 콤보별 음악 마법을 사용합니다. 극장은 금빛 지휘봉·오르간, 옥상은 키타·스피커 음파, 우주는 신스 빔·궤도 탄환, 판타지는 하프 현·별빛 화살로 구분됩니다. ASDJK·멀티 터치 입력 조명, 롱노트 유지/완주, 8·24·48콤보 단계와 64콤보 피날레를 제공합니다. 실제 검증 결과와 범위는 `docs/world-attacks-v7-verification.md`에 기록되어 있습니다.

현재 구현: `docs/superpowers/plans/2026-11-09-fullscreen-rhythm-v3.md`. 판정 추적: `docs/rhythm-rea-audit.md`. 추가 실연 8곡의 녹음 출처·이용 조건: `docs/music-expansion-v3.md`. 디자인 금지 규칙은 루트 `AGENTS.md`에 기록되어 있습니다. 녹색 선택 패널·카드 격자·장식용 헤더와 푸터를 다시 추가하지 않습니다.

실제 클래식 연주와 오리지널 신스 음악을 들으며, 위에서 떨어지는 노트 바를 비트에 맞춰 직접 터뜨리는 초등학생용 2D 음악 감상 리듬 게임입니다.

## 실행

```powershell
npm install
npm run dev
```

기본 주소는 `http://127.0.0.1:5173`입니다.

## 빌드

```powershell
npm run build
```

## 조작

- PC: 짧은 노트 바는 클릭하고 긴 노트 바는 누른 채 유지
- PC 키보드: `A S D J K`로 다섯 레인 연주
- 태블릿·모바일: 짧은 노트 바는 터치하고 긴 노트 바는 손가락으로 길게 누르기
- 일시정지: `Escape`

노트가 화면 아래의 넓은 비트 존에 들어왔을 때 누르면 `PERFECT`, `GREAT`, `GOOD` 판정을 받습니다. 긴 바는 머리를 잡은 뒤 꼬리가 비트 존에 닿을 때까지 유지합니다. 설정에서 교실 스피커의 출력 지연을 `±250ms` 범위로 보정할 수 있습니다.

## 수록곡

- MUMU ORIGINAL: 네온 런
- MUMU ORIGINAL: 구름 점프 (묻고 답하기)
- MUMU ORIGINAL: 로봇 퍼레이드 (오스티나토)
- 모차르트: 터키 행진곡
- 오펜바흐: 캉캉
- 로시니: 윌리엄 텔 서곡 피날레
- 브람스: 헝가리 무곡 5번

클래식 네 곡과 네온 런은 약 70~80초, 구름 점프(132 BPM)와 로봇 퍼레이드(124 BPM)는 약 55초입니다. 클래식 네 곡은 실제 연주 기반 차트를 사용하고, 오리지널 신스 세 곡은 곡마다 하나의 결정론적 악보에서 음원과 노트(네온 런 344개, 구름 점프 109개, 로봇 퍼레이드 115개)를 함께 생성합니다.

## 음악 제작

오리지널 신스곡은 외부 샘플 없이 NumPy로 드럼, 베이스, 패드, 아르페지오, 리드를 합성하고 FFmpeg로 OGG와 M4A를 만듭니다.

```powershell
npm run build:music
```

- 시드, BPM, 악보가 고정되어 같은 음원과 차트를 재현합니다.
- OGG가 재생되지 않는 브라우저에서는 M4A를 자동으로 사용합니다.
- 음원과 차트가 같은 악보에서 생성되어 온셋 분석 오차가 없습니다.

클래식 실제 연주 차트를 다시 만들려면 다음 명령을 사용합니다.

공개 라이선스의 실제 연주를 수업용 길이로 편집하고, 녹음의 어택과 음역을 분석해 화면 노트를 생성합니다. 원본은 `tmp/`에 내려받으며 저장소에는 편집한 OGG만 포함합니다.

```powershell
pip install librosa
python tools/build_real_music.py
```

- FFmpeg로 구간 편집, 페이드, 라우드니스 정규화를 처리합니다.
- librosa의 온셋 강도와 주된 음역을 이용해 곡별 5레인 차트를 만듭니다.
- 노트 팝은 음정이 없는 짧은 Web Audio 효과라 원연주의 화성과 충돌하지 않습니다.
- 브라우저는 선택한 곡의 실제 연주 OGG만 먼저 읽습니다.

출처와 라이선스는 `THIRD_PARTY_ASSETS.md`에 정리되어 있습니다.

## 그래픽 제작

V8은 생성 이미지와 코드 그래픽을 결합합니다. 곡 표지와 무대 배경에는 최적화된 WebP를 사용하고, 노트와 판정, 버튼, 글자와 효과는 코드로 그립니다.

- 중앙: 정수 픽셀 9:16 스테이지. Canvas 2D가 레인·노트·판정 영역을 그리고, 게임 진입 후 CanvasKit WASM을 지연 로드해 Skia GPU 레인 광원, 홀드 에너지, 타격 파편을 같은 `stageLayout`에 맞춰 그립니다. 실패 시 Canvas 2D 효과로 전환합니다.
- 주변: WebGL2 뮤직비디오가 포털 → 도시·파형 → 감상 → 가락 리본 → 만화경 피날레 장면을 `AudioEngine` 게임 시간 기반 `visualTimeline`에 동기화합니다. 컨텍스트 손실이나 WebGL2 미지원 시 Canvas 2D, 이어서 CSS 그라디언트로 전환합니다.
- 데스크톱·태블릿 가로는 좌우 MV와 장면 캡션, 세로 화면은 스테이지를 폭에 맞추고 남는 위아래를 MV로 채웁니다. 844x390 같은 낮은 가로 휴대폰에서는 회전 안내를 띄우고 자동으로 일시정지합니다.
- 곡별 표지·미션·결과에는 `public/assets/art/v8/`의 곡별 이미지가 사용되며, 카드 이미지 로딩 실패 시 Canvas 2D 모티프가 대신 보입니다.
- 미션에서 쉬움(보이는 바 직접 터치)과 도전(박자 판정)을 선택할 수 있습니다. 최고 점수는 모드별로 저장합니다.
- 구름 점프의 묻는 신스와 대답하는 벨 예시는 `npm run build:listening`으로 실제 악보에서 다시 생성할 수 있습니다. 전체 곡의 분리 음원이 아닌 짧은 예시입니다.
- 설정의 "화면 효과 품질"로 MV 해상도·fps와 Skia 사용 여부를 조절합니다. "자동"에서는 실제 프레임 시간을 측정해 느린 프레임이 이어지면 한 단계 낮추고, 오래 안정적일 때만 한 단계씩 되돌립니다(`src/render/quality.ts`의 `AdaptiveQuality`).
- 일시정지나 탭 숨김 중에는 게임 루프, MV, Skia가 모두 멈춥니다.

깊이감은 Blender 5.x에서 설계합니다. 헤드리스 Blender가 카메라, 바닥 레일, 터널 링, 별 레이어, 도시 블록을 3D로 배치하고 카메라 투영 좌표만 `src/content/stageGeometry.generated.ts`로 내보냅니다. 렌더 이미지는 만들지 않습니다.

```powershell
npm run build:art
```
