# 입력감과 그래픽 개선 작업계획

목표: 소리와 화면으로 누름·명중·합주를 구분한다. 비트북은 비교 자료이며 코드·스킨·음원을 가져오지 않는다. 기존 5키, 원곡, 픽셀 세계와 퀴즈를 유지한다.

- [x] 입력음: 키보드와 터치가 공통으로 쓰는 입력 지점에 짧은 클릭음을 연결한다. 같은 입력 소스는 중복 재생하지 않는다. 일시정지에서 입력음만 끌 수 있고, 판정음과 반주는 유지한다.
- [x] 채보: 구름 점프는 첫 두 마디에서 박을 예열하고, 초급 본편은 가락의 주요 음을 따라간다. 중급은 가락과 빈 구간의 실제 베이스, 고급은 일부 첫박의 가락과 베이스를 두 레인에 함께 배치한다. 동일 시작 시점과 출처, 롱노트 충돌 및 4단계 보스 완주 가능성을 검사한다.
- [x] 그래픽: 어두운 다섯 레인과 색이 있는 판정 받침대를 고정한다. 누름의 좁은 빛, 명중의 짧은 픽셀 충격, 두 노트의 연결선이 각각 다른 정보를 준다. 판정선·히트박스는 움직이지 않는다. 모션 감소 설정에서는 새 폭발 확장과 글자 이동을 줄인다.
- [x] 검증: 전체 테스트와 빌드, 키보드 초·중급과 모바일 고급 완주, 입력음 스위치, 롱노트·두 손가락·퀴즈 복귀, 데스크톱·모바일 스크린샷을 확인한다.

이 작업은 로컬 시범이다. 새 채보는 구름 점프에만 적용하고 공개 배포는 별도로 진행한다.

## 구현 확인

- 전체 테스트 399개, 배포용 빌드, 작곡 원본 이벤트 대조 통과.
- Chrome 키보드: 초급 70개, 중급 98개. Chrome 터치 에뮬레이션: 고급 137개. 세 플레이 모두 수집률 100%, 보스 4/4 처치, 오답 수정 후 퀴즈 5/5.
- 빈 레인 입력은 점수 없이 28ms 클릭 재생 1회, 끈 상태는 0회. 키보드와 터치에서 검증했다.
- 첫 터치 검사에서 롱노트 끝과 합주 판정창이 맞닿는 구간을 발견했다. 합주 앞의 롱노트 꼬리와 반 박을 띄운 뒤, 최종 고급 완주 중 최대 접점 수는 2였다.
- 화면 및 재현 기록: `output/note-knights/world-journey/feel-pulse/`, `feel-groove/`, `feel-melody-final/`. 실기기에서의 소리 지연과 주관적 손맛은 자동화로 검증하지 않았다.
