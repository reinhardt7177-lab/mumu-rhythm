# 개념24문항 쉬운 말 검토

질문·세 보기·정답 해설·오답별 설명을 모두 읽었다. 문제 ID·학년·정답 번호와 악보를 그대로 두었다. 아래의 유지는 단순 미확인이 아니라 문장을 읽고 그대로 두어도 뜻이 분명하다고 판단한 항목이다.

| ID | 처리 | 검토 내용 |
| --- | --- | --- |
| concept-34-pulse | 수정 | 긴 '박의 흐름' 설명을 같은 간격으로 두 번 짚는 행동으로 설명 |
| concept-34-rhythm | 수정 | 걷기와 손뼉의 변화를 짧은 순서로 나눔 |
| concept-34-rest | 수정 | '생략·시간을 차지' 대신 기다리는 시간과 친구와 시작하는 때로 풀이 |
| concept-34-duration | 수정 | 질문을 나누고 음표 개수와 박 수를 분명히 구별 |
| concept-34-pitch | 수정 | 높은 음과 큰 소리의 차이를 건반을 누르는 행동으로 설명 |
| concept-34-melody | 수정 | 이웃한 음의 움직임과 같은 음 반복을 쉬운 말로 설명 |
| concept-34-dynamics | 수정 | '균형·조절' 대신 북 소리를 줄여 노랫말이 들리게 하는 행동 |
| concept-34-tempo | 수정 | 같이 시작하고 같은 리듬을 모두 친 조건을 짧게 나눔 |
| concept-34-timbre | 수정 | 목소리를 알아듣는 상황으로 음색 비교 질문을 풀어 씀 |
| concept-34-harmony | 수정 | 두 음을 같은 때에 내는 것과 번갈아 부르는 것을 구별 |
| concept-34-form | 수정 | 메기고 받는 방식을 한 사람의 앞소리와 여럿의 약속한 답으로 설명 |
| concept-34-gugak | 수정 | 직전의 쉬운 질문은 유지하고, 남아 있던 '힘의 흐름' 피드백을 묶음의 첫 소리로 바꿈 |
| concept-56-pulse | 수정 | 큰 박의 묶음 크기와 묶음 수를 짧게 질문 |
| concept-56-rhythm | 수정 | '시간의 틀·조건 유지' 대신 빠르기와 마디 길이를 그대로 두기로 표현 |
| concept-56-rest | 수정 | '내 파트·합주의 흐름' 대신 내가 쉬는 마디와 지휘 신호 |
| concept-56-duration | 유지 | 한 박의 기준, 점4분음표와 반 박 덧셈이 짧고 명확함 |
| concept-56-pitch | 수정 | 음이름·계이름은 그대로 배우되 '해당하는' 대신 서로 '짝'으로 풀이 |
| concept-56-melody | 수정 | '모양·조건' 대신 파에서 이웃한 음으로 두 번 올라가는 행동 |
| concept-56-dynamics | 수정 | '가장 직접적인·돌아보기' 대신 녹음에서 확인할 점 질문 |
| concept-56-tempo | 수정 | '계획을 살림·길이 관계' 대신 박 사이 간격과 그대로인 박 수 |
| concept-56-timbre | 수정 | '비교 조건·다른 요소에 끌림' 대신 높이·길이·세기와 들리는 차이 |

| concept-56-gugak | 수정 | 음절을 바람의 바·람으로 설명하고 한배를 빠르기로 풀이 |

현장 학생의 읽기·풀이 시간은 아직 측정하지 않았다. 쉬운 말로 다듬은 것과 실제 독해 난이도가 검증된 것은 구분한다.
