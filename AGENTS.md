# Project Design Rules

These rules record the user's explicit feedback of 2026-11-09. Later explicit user directions take precedence.

- Do not reintroduce muted green or teal background panels, a green song-selection band, or a generic card-grid dashboard. Green within an actual forest illustration is not prohibited.
- Use the full browser viewport for the game. Avoid a centered max-width page surrounded by unused margins.
- Remove decorative header slogans, repeated game titles, unnecessary footers and explanatory filler. Keep essential navigation compact.
- Song selection is a usable music library over a game world, not a marketing landing page. Prefer compact track rows to repeated image cards.
- Give each era a distinct cast and atmosphere. All heroes and monsters use real sprite image assets, not geometric placeholder drawings.
- Conventional falling-bar mode aligns the note center, hitline, touch hit-test and audible clock. Preserve accessible explore mode separately.
- Do not report music added until the audio files, chart, pre-play introduction, listening question and exact recording credits are connected and tested.
- Validate the actual full-screen desktop and mobile screenshots before claiming a redesign is finished. User feedback about appearance is a design requirement, not a request for another layer of decoration.
