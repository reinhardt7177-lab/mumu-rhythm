## 구성과 곡별 연결

각 묶음에는 서로 다른 개념의 문항 5개와 개념 메모 3개가 있다. 메모는 2개/2개/1개 개념을 묶어, **다섯 문항 모두 사전 학습 메모와 연결**된다. 첫 메모에 곡명과 열린 감상 제안을 넣었다.

21개 개념에 학년군별 1개씩 총 **42개 독자 작성 문항**을 두고, 곡마다 다른 5개 개념 조합을 선택한다. 28개 묶음의 총 문항 슬롯은 140개다. 140개가 모두 서로 다른 문장이라고 주장하지 않는다. 예컨대 현악기 음색 비교는 현악 사중주에서, 반복 반주 개념은 오리지널 오스티나토 곡에서 학습하도록 관련성이 있는 곳에서만 재사용한다. f/p 문항은 모든 곡에 붙는 고정 문항이 아니다.

곡 연결의 근거는 읽은 프로젝트의 `src/quest/worlds.ts`, `src/quest/catalog.ts`, `src/content/songs.ts`, `src/content/extraSongs.ts`다. 녹음의 외부 출처와 연주자 정보는 기존 카탈로그의 소유이며 이 모듈에서 재검증하거나 바꾸지 않았다. 다음은 **메타데이터에 근거한 감상 맥락**이지, 여기서 실제 음원을 재청취하여 확정한 분석이 아니다.

## 내용 안전 규칙

- 게임의 `beatsPerBar`, 노트 레인, 자동 검출 onset 또는 MIDI 정보를 녹음의 실제 박자·조성·악기·형식 증거로 사용하지 않는다. 모듈은 차트나 음원을 import하지 않는다.
- 기존 미션 첫 문항을 자동 복제하지 않는다. 특히 강한 첫 박이나 특정 악기가 들렸다는 문항은 녹음 구간별 검증 없이는 정답으로 고정하지 않는다. 부모 UI 통합 시 첫 문항이 `song.mission.question`과 같다는 이전 테스트는 이 API의 계약이 아니다.
- 감상 제안은 정답을 강요하지 않는다. 채점 문항은 명시한 예시·조건으로 답할 수 있으며 특정 녹음에 그 화음·리듬·형식이 있다는 단정이 아니다.
- 4분음표가 항상 한 박이라는 설명을 하지 않는다. 상대 길이를 기본으로 하며, 박 수를 물을 때는 기준 음표를 명시한다.
- 화음의 동시 울림과 한 음씩 펼치는 연주를 구별한다. 여러 악기 소리가 겹친다는 이유만으로 특정 화음이 있다고 단정하지 않는다.
- 빠르기와 셈여림, 높이와 세기, 짧게 끊기와 빨라지기를 구별한다.
- 감정·장면 자체에는 단일 정답을 강제하지 않는다. 감정 관련 문항은 근거 나누기 또는 명시된 표현 조건을 평가한다.
- 기능화성, 화음 로마숫자, 대위법 분석은 포함하지 않는다. 국악·지역 문화 등 교육과정 전체를 다루는 모듈도 아니다.

## 통합 API

```ts
export type GradeBand = '3-4' | '5-6';
export interface LearningPack {
  grade: GradeBand;
  concepts: { title: string; body: string }[];
  questions: {
    q: string;
    a: string[];
    correct: number;
    why: string;
    concept: string;
  }[];
  sourceUrls: string[];
}
export function learningFor(songId: string, grade?: GradeBand): LearningPack;
```

`grade`는 기본값 `'3-4'`. `correct`는 `a` 배열의 **0부터 시작하는 인덱스**다. 각 문항에 독립적인 `why` 해설을 사용한다. 모든 호출은 새 배열과 객체를 반환하므로 UI가 반환값을 변경해도 다른 호출에 전파되지 않는다. 함수는 I/O, 전역 상태 변경, 무작위화를 사용하지 않는다. 알 수 없는 ID와 `__proto__`, `constructor`에는 곡·녹음 사실을 단정하지 않는 중립 학습 묶음을 반환한다.

UI에는 3~4학년/5~6학년 선택, 시작 전 개념 메모 3개, 결과의 다섯 문항, 문항별 정오답 및 이유, 교육부 원문 링크가 연결되어 있다. 오답 선택 후 다시 확인할 수 있다. 세 문제용 고정 분모와 모든 곡에 붙던 반복/f 공통 문항은 실제 게임 흐름에서 사용하지 않는다. 사전 개념을 펼쳐도 연주 시작 버튼은 고정된 아래 영역에 남는다.

## 검증

`npm test -- src/quest/learning.test.ts`는 실제 카탈로그 14개 ID × 두 학년군, 메모/문항 수, 선택지 중복, 정답 인덱스, 해설 존재, 문항별 사전 개념 연결, 학년별 문항 차이, 14개 개념 조합 다양성, 상대 길이/화음 구별, 안전 fallback 및 반환값 독립성을 검사한다. 선택지의 음악적 진위와 난이도는 테스트만으로 증명되는 것이 아니므로 위의 원문 범위와 내용 안전 검토를 함께 적용한다.
