# 활동 24개와 연결 수업 쉬운 말 검토

활동의 제목·과제·준비물·절차·확인 질문·돌아보기까지 모두 읽었다. 24개 모두 적어도 한 곳을 수정했다. 활동 ID, 학년, 연결 단원과 수업 성취기준은 유지했다. 책상에서 절차를 대조했으며, 실제 학급에서 활동을 실시한 것은 아니다.

| 활동 ID | 검토·수정 내용 |
| --- | --- |
| activity-pulse-3-4 | 목소리만 네 박 쉬고 무릎은 같은 간격으로 움직이게 나눠 설명했다. |
| activity-pulse-5-6 | 앞 네 박과 뒤 네 박에서 한 박에 부르는 글자 수를 각각 적었다. 역할을 바꾼 뒤 잘 맞은 곳은 그대로 두게 했다. |
| activity-rhythm-3-4 | 티티를 새로 더하는 것이 아니라 다른 칸의 타와 서로 바꾸게 했다. |
| activity-rhythm-5-6 | 뒤 두 박은 그대로 두는 범위를 먼저 알려 주고, 2분음표는 두 박 동안 한 소리로 이어 내도록 했다. |
| activity-rest-3-4 | 쉬는 칸을 종이에 표시하고, 기다린 뒤 다음 박에 손뼉 치게 했다. |
| activity-rest-5-6 | 짝은 박을 짚고 나는 두 박 쉬었다가 셋째 박에 시작한다고 역할을 나눴다. |
| activity-duration-3-4 | 소리 두 번과 소리 한 번을 직접 불러 보고, 소리 횟수와 전체 박 수를 따로 세게 했다. |
| activity-duration-5-6 | 반 박짜리 네 칸으로 점4분음표와 8분음표의 길이를 눈으로 확인하게 했다. |
| activity-pitch-3-4 | 두 번째 음을 듣고 손을 올리기·내리기·그대로 두기로 답하게 했다. |
| activity-pitch-5-6 | 선생님이나 악기로 기준음을 듣고 오선의 음표를 짚는 순서를 밝혔다. 계이름 레와 음이름 라(D)를 구별한다. |
| activity-melody-3-4 | 올라가고 내려가는 곳은 선으로 그리고, 중간 음을 건너뛴 곳은 따로 표시하게 했다. |
| activity-melody-5-6 | 네 음 사이의 세 곳을 하나씩 짚고, 도·도·레·솔로 같은 음·차례가기·뛰어가기 예를 들었다. |
| activity-dynamics-3-4 | p와 f의 뜻을 붙여 쓰고, 목에 힘을 주지 않으면서 두 번의 빠르기를 비교하게 했다. |
| activity-dynamics-5-6 | 앞 네 박은 조금씩 세게, 뒤 네 박은 조금씩 여리게 한다는 순서를 밝혔다. |
| activity-tempo-3-4 | 같은 말을 여러 빠르기와 크기로 말한 뒤 무엇이 빨랐는지, 무엇이 컸는지 따로 말하게 했다. |
| activity-tempo-5-6 | 한 박 안의 손뼉 수를 늘리는 경우와 박 사이를 좁히는 경우를 따로 해 보게 했다. |
| activity-timbre-3-4 | 종이 구기기와 손뼉으로 소리가 처음 나고 사라지는 모습을 말하게 했다. |
| activity-timbre-5-6 | 높이·길이·세기를 비슷하게 맞추고, 직접 들은 것과 아직 들어 보지 않은 생각을 구별하게 했다. |
| activity-harmony-3-4 | 두 사람이 서로 다른 음을 맡아 번갈아 부른 다음, 함께 부르며 서로의 소리를 듣게 했다. |
| activity-harmony-5-6 | 도·미·솔을 한꺼번에 내는 연주와 앞 소리가 끝난 뒤 다음 음을 내는 연주를 비교하게 했다. |
| activity-form-3-4 | 한 사람이 앞소리를 내고 나머지가 정해 둔 뒷소리로 답하는 역할을 밝혔다. |
| activity-form-5-6 | a가 다시 나오는 곳을 짚고 어떤 소리를 듣고 알았는지 짝에게 묻게 했다. |
| activity-gugak-3-4 | '장단이 돌아오는 자리'를 '장단이 한 번 끝나고 다시 시작할 때'로 풀고, 세는 힘을 주고 풀어 가는 모습으로 설명했다. |
| activity-gugak-5-6 | 앞 음절 늘이기와 뒤 음절 늦추기를 박 안에서 해 본 뒤, 원래대로 돌아가 한배만 바꾸는 순서로 나눴다. |

## 연결 수업 12개·학년별 24화면

두 학년의 소개·예시·따라 하기·주의할 점과 그림 설명을 검토했다. 기존 그림 속 음표와 도표 칸의 내용은 그대로 두고 필요한 풀이를 본문이나 그림 설명에 붙였다.

| 단원 | 쉬운 말로 정리한 내용 |
| --- | --- |
| 박 | 무릎을 짚으며 박을 느끼고, 6/8박자의 큰 박은 세 음씩 두 묶음으로 설명했다. |
| 리듬 | 타와 티티를 박 안에서 부르고, 앞 두 박만 바꾸는 범위를 밝혔다. |
| 쉼표 | 준비박은 마지막 한 박까지 세고, 두 마디를 쉬면 셋째 마디에서 시작한다고 설명했다. |
| 음표 길이 | 음표의 모양과 소리 길이를 나눠 설명하고, 반 박씩 세어 점음표 길이를 확인하게 했다. |
| 높낮이 | 셋째 줄이 음표 머리 가운데를 지난다는 표현으로 줄과 칸을 구별했다. |
| 가락 | 음이 움직이는 방향과 이웃한 음을 건너뛰는지를 따로 살피게 했다. |
| 셈여림 | 어디서 소리가 커지고 작아졌는지 말하게 하고, 박 간격은 그대로 두게 했다. |
| 빠르기 | '점진적'을 '조금씩'으로 바꾸고, 박 간격과 박 안의 소리 수를 비교했다. |
| 음색 | 소리마다 느껴지는 특징을 말로 표현하고, 관과 리드의 뜻을 풀이했다. |
| 화음 | 세 음을 한꺼번에 울리는 소리와 한 음씩 내는 소리를 구별했다. |
| 음악의 부분 | '근거로 설명' 대신 어떤 가락이나 리듬을 듣고 a를 알아챘는지 묻는다. |
| 국악 | 장단의 다시 시작, 힘을 주고 푸는 세, 말붙임새와 한배를 행동과 소리로 구별했다. |
