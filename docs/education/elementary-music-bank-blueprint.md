## 1. 결론과 수량의 의미

권장 목표는 **독립 제작 평가 항목 480개 = 자동채점 문항 400개 + 수행·표현 과제 80개**다. 약 60개 세부 학습 목표에 평균 8개 항목을 배정한 제작 계획이며 교육부가 정한 문항 수가 아니다. 원문 대조, 자산 확보, 교사 검토와 학생 시범 적용에 따라 조정한다.

첫 공개 묶음은 자동채점 96문항과 수행 과제 24개, 합계120개로 범위를 줄인다. 현재 게임의 선택형 결과 화면에 수행 과제까지 억지로 넣지 않는다. 먼저 그림·소리 문제와 채점 구조를 완성하고, 활동 과제는 별도 교사용/학생용 활동지나 전용 화면에 연결한다.

현재 앱은21개 개념에 독립 작성42문항을 갖고 있다. 14곡×2학년군×5문항=140은 **배치 슬롯 수**이지 독립 문항 수가 아니다. 기존42개는 재검수 후 채택 여부를 정하며, 새 목표 수에 무조건 더하지 않는다. 선택지 순서, 인명, 숫자만 바꾼 것은 변형으로 별도 집계한다.

## 4. 위계: 학년만 나누지 않는다

자료 구조: `학년군 → 영역/단원 → 학습 목표 → 선수 목표 → 교육자료 → 안내 연습 → 평가 → 오답 피드백 → 재도전`.

선수 관계는 하나의 줄이 아니라 여러 목표가 연결된 구조로 관리한다. 국악을 서양 기보를 마친 뒤에만 배우는 부록으로 두지 않는다.

| 학습 경로 | 준비 경험 → 기초 개념 → 구별·적용 → 확장 |
| --- | --- |
| 박·리듬 | 일정하게 움직이기 → 박과 리듬 구별 → 음표·쉼표의 상대 길이 → 듣기와 악보 대응 → 조건에 맞는 리듬 만들기 |
| 음높이 | 높낮이 듣기 → 올라감·내려감·같음 → 차례·뛰어가기 → 기초 기보·음이름/계이름 → 장·단음계 비교 |
| 어울림 | 하나와 여럿의 소리 → 가락·반주 구별 → 함께/차례로 울림 → 화음 → 고학년 주요3화음 활용 |
| 국악 | 장단에 몸으로 반응 → 장단의 순환·세 → 구음·장단꼴·말붙임새 → 한배 변화·시김새·토리 → 감상과 표현 |
| 구성 | 같은 부분 알아듣기 → 같음·다름 표시 → 메기고 받기·ab → 근거를 들며 간단한 구성 설명 → 조건에 따라 일부 바꾸기 |

학년군 적합성과 난이도는 별도 태그다. 난이도는 `단일 요소 인식·구별 / 비교·조건 적용 / 복합 조건·새 맥락 활용`으로 설계하고 실제 난이도는 학생 시범 적용으로 조정한다. 상위 목표의 진입을 시험 점수 하나로 막지 않고 선수 목표 연습을 제안한다.

## 5. 규모 제안: 약60목표,480항목

아래 배정은 제작 예산을 산정하기 위한 초안이다. 겹치는 개념은 하나의 목표 ID로 관리하며 여러 단원에 태그로 연결해도 중복 문항으로 세지 않는다.

| 음높이·가락·기초 기보·음계 | 10 | 68 | 12 | 80 |

400개 정답형 중 제시·응답의 중심 유형 배정 예시는 그림/악보120, 실음 듣기160, 개념/상황 판단80, 조건이 분명한 배열/완성40이다. 서로 겹치는 유형을 중복 합산하지 않는다. 이 수치는 실제 문항별 검수를 마치기 전 확정값이 아니다.

80개 수행 과제는 리듬 따라 치기, 짧은 표현·바꾸기, 감상 근거 나누기, 합주와 성찰 등에 배정한다. 여러 답이 가능한 창작 과제를 객관식으로 바꾸어 자동 정오답 처리하지 않는다. 두드리기 자동 평가는 기기 지연 보정과 허용 오차 검증 전까지 제한한다.

### 제작 단계

1. **1차120항목:** 그림32+실음40+개념24=자동채점96, 수행24. 접근성과 채점·해설·재생 기능을 실제 학생 흐름으로 검증한다.
2. **누적240항목:** 국악·기보·가락·음색을 확대하고 두 학년군의 기초/적용 문항을 균형 있게 배치한다.
3. **누적480항목:** 공식 범위에 대한 누락·중복 점검 후 전 단원에 연습·평가·보충 경로를 연결한다. 단원별 분량은 검토 결과에 따라 조정한다.

## 6. 교육자료 한 묶음의 완성 기준

각 목표에는 교사용 근거·유의점, 학생용 짧은 설명, 정확한 기호/그림, 검수된 소리 예시, 안내 연습, 평가 항목, 문항별 해설, 오개념별 보충 활동을 연결한다. 용어만 맞히는 카드 모음을 교재 완성이라고 부르지 않는다.

예시 목표: **음표와 쉼표의 길이를 리듬과 연결하기**.

- 선수 경험: 일정한 박 유지, 소리/쉼 구별, 길이 비교.
- 학습 조건: 예시에서4분음표를 한 박으로 정한다. 모든 곡에서 항상 한 박이라고 일반화하지 않는다.
- 개념: 같은 기준에서2분음표는4분음표 길이의 두 배이며, 쉼도 음악의 시간을 차지한다.
- 시각 자료: 표준 악보 기호로 음표·쉼표를 렌더링한다. 악보 기호를 장식 그림처럼 임의 변형하지 않는다.
- 듣기 예시: 동일한 빠르기·음색·높이로 서로 다른 리듬을 제시하고, 듣는 차이 외의 단서를 통제한다.
- 안내 연습: 소리와 쉼을 따라 박을 짚어 보고 악보에서 해당 위치를 찾는다.
- 평가: 그림의 길이 관계 구별, 들은 리듬과 악보 연결, 조건에 맞는 빈칸 완성, 리듬 따라 표현하기를 나눈다.
- 피드백: 쉼을 생략함, 소리 개수와 전체 길이를 혼동함, 잘게 나눈 리듬을 빠르기 변화로 오해함을 구분하여 보충한다.

## 7. 그림·실음 문항의 품질 계약

그림은 음표 머리·기둥·꼬리, 쉼표 위치와 형태, 오선 간격을 정확히 표시한다. 악보를 확대할 수 있고 키보드·터치로 답할 수 있어야 한다. 교육적 장식과 정답 판단에 필요한 표기는 구분한다.

소리는 짧은 재생·다시 듣기·중지·음량을 제공하며 자동재생하지 않는다. 다른 문제 재생, 재도전, 곡 선택 복귀, 새 게임 시작 시 이전 소리를 정지한다. 로드 실패는 정답 오답이 아니라 재시도 가능한 오류로 처리한다. 선택지나 접근성 이름에 듣기 문제의 정답이 먼저 드러나지 않도록 검토한다.

음색 구별은 가능하면 높이·길이·세기를 통제한 실제 연주 샘플을 사용한다. 샘플 악기를 렌더링한 경우 실제 단독 녹음과 구별하여 기록한다. 셈여림 비교 문항에는 세기 차이를 없애는 일괄 음량 정규화를 적용하지 않는다. 청각 과제를 텍스트로 대체하면 측정 목표가 달라질 수 있음을 표시하고 별도 학습 경로를 제공한다.

모든 소리에는 파일, 구간, 출처, 연주/녹음 정보, 이용 조건, 변경 내용, 검수 기록이 있어야 한다. 곡명, 게임 레인, 자동 생성 차트, 악기 메타데이터만으로 실제 청취 정답을 확정하지 않는다. 무료 공개와 재배포·편집 허용을 혼동하지 않는다.

국악 자산 후보: 국립국악원 국악기 디지털 음원 및 교육자료. 디지털 음원 서비스 소개는 출처표시 이용 방식을 안내하지만, 개별 자산의 현재 조건을 다시 확인한다. 보도자료 자체의 이용 조건을 음원에 그대로 적용하지 않는다.

## 8. 문항 데이터와 검수

필수 항목: 고유ID, 목표ID, 학년군, 관련 성취기준과 문서 버전·쪽수, 선수 목표, 제시 유형, 난이도(가설), 정답/허용답, 오답별 오개념, 해설, 교육자료ID, 시각/음원 자산ID, 채점 방식, 원문항/변형 관계, 권리 기록, 음악·문장·접근성 검수 상태, 시범 적용 결과.

정답 오류·복수 정답·권리 미확인·미검증 음원 주장은 출시 보류 사유다. 오답지는 실제 혼동을 반영하고 종이 크기·작곡가 이름 같은 무관한 선택지로 쉽게 지우는 문제를 줄인다. 느낌·장면·취향에는 단일 정답을 강요하지 않는다. 창작·합주·성찰은 조건 충족, 소리 근거, 수정 과정 등을 보는 루브릭을 사용한다.

검토 루브릭은 목표 정합성, 음악적 정확성, 자극 근거, 채점·해설, 독립성과 오답지, 접근성, 권리의7축으로 제안한다. 점수로 치명 결함을 상쇄하지 않는다. 교사 검토와 학생 시범 적용 전에는 ‘현장 검증된480문제’라고 표시하지 않는다.

## 9. 게임 적용 원칙

게임 종료마다 전체 문제를 길게 노출하지 않고, 해당 곡·선수 목표·이전 오개념에 맞춘3~5문제를 고른다. 학습 모드에서는 설명과 예시를 충분히 제공하고, 평가 모드와 반복 노출 기록을 구분한다. 게임 키 입력 점수로 음악 이해도 전체를 판정하지 않는다.

이번 문서의 산출물은 원문 기반 범위·위계·규모·검수 설계다. 음표 그림과 청취 문제의 구현은 이 설계를 바탕으로 진행할 다음 작업이며, 현재 배포된 게임에 이미 추가되었다고 주장하지 않는다.
