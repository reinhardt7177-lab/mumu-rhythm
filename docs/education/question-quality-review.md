# 120항목 문제은행 내용 품질 개선

검토일: 2026-11-10. 이 문서는 배포 전 로컬 수정본의 내용 검토 기록이다. 기존 공개 배포본의 기능 검사와 구분한다. 후속 배포 여부는 해당 커밋의 배포 기록에서 확인한다.

## 범위와 기준

- 구성은 그림 32문항, 듣기 40문항, 개념 24문항, 활동 24개로 유지했다. 활동을 자동 채점 문제로 세지 않는다.
- 96개 채점 문항의 정답 유일성, 그림·소리의 필요성, 답을 알려 주는 문장, 오답의 개연성, 학년 적합성, 교육자료 연결을 검토했다.
- 기존 배포 커밋 `db78a740`과 구조화된 JSON을 비교하면 42문항(그림16·듣기11·개념15), 10개 단원 자료, 10개 활동이 바뀌었다. ID와 학년군은 유지했다.
- 교육과정 전체를 평가하는 표준화 검사라는 뜻은 아니다. 초등 3~4·5~6학년군의 승인된 1차 핵심 범위다.

## 주요 수정

| 발견한 문제 | 바꾼 내용 |
| --- | --- |
| 음이름 보기의 `라(A)` 오류 | 우리나라 음이름은 다(C)·라(D)·마(E)·바(F)·사(G)·가(A)·나(B). 해당 보기를 `라(D)`로 고치고 계이름과 구분하는 자료를 보강했다. |
| 그림의 음표·쉼표 이름이나 음표 위치를 문장이 먼저 알려 줌 | 그림을 보고 판별하도록 중복 단서를 제거했다. 필요한 한 박의 기준은 남겼다. |
| 듣기 보기 글자가 리듬을 그대로 읽어 줌 | 네 리듬-악보 선택 문항의 보기 이름을 가·나·다로 바꾸고, 실제 음 길이 배열과 일치하는 악보가 하나인지 별도로 계산했다. |
| 듣기 전에 긴 음의 위치나 나뉜 박을 알려 줌 | 듣고 비교해야 하는 중립적인 질문으로 고쳤다. |
| 짧게 끝나는 관악기 샘플의 잔향을 쉼으로 오해할 수 있음 | 쉼 찾기 두 문항을 충분히 긴 피아노 녹음과 네 번의 낮은 준비박으로 바꿨다. 모든 쉼 듣기 문제의 준비박·이벤트·녹음 길이를 검사한다. |
| 고학년 문제가 저학년 단순 인식과 비슷함 | 여덟 음 가락의 처음·끝 비교, 피아노·트럼펫·플루트 중 관악기 묶기 등으로 구분했다. |
| 박자·셈여림 문제를 음높이 같은 무관한 보기로 쉽게 소거할 수 있음 | 같은 음악 요소 안에서 혼동할 만한 오답을 만들고, 해당 오개념에 맞춘 해설로 바꿨다. |
| 고학년 응용이 연결 자료에서 배우지 않은 내용까지 나감 | 조옮김·긴자진 등은 현재 가르친 음이름, 점음표, 말붙임새·한배·세의 적용으로 조정했다. |
| 국악 시간 비교가 좁은 화면에서 나란히 줄바꿈됨 | 두 예시를 같은 왼쪽 기준의 독립된 행으로 표시했다. 점은 같은 길이의 시간 눈금이며, 각 구음은 한 박의 시작이라는 조건을 밝혔다. |
| 실제로 지속할 수 없는 도구로 긴 소리를 표현하는 활동 | 목소리 또는 지속 가능한 악기를 쓰게 했다. 짝 자료와 관찰 기준도 보강했다. |

## 검증 기록

- 전체 단위 검사: 37파일, 386검사 통과. Vite/TypeScript 빌드와 교육자료 내보내기 일치 검사도 통과했다.
- 별도 내용 회귀 검사: 악보 길이·윤곽·형식 비교의 유일한 정답, 듣기 이벤트와 보기 악보의 일치, 쉼 듣기 준비박과 녹음 지속 길이, 학습 자료와 평가 범위의 연결을 확인한다. 단순히 데이터의 `correct` 값을 다시 읽어 통과시키는 검사와 구분한다.
- 개발 서버 브라우저 검사: 96문항, 24활동, 24개 학년별 자료 화면, 실제 녹음을 사용하는 60개 듣기 클립의 오프라인 렌더링, 6종 악기의 실시간 출력, 재생 실패·취소·재시도 처리를 확인했다. 데스크톱·태블릿 가로/세로·모바일 배치도 확인했다.
- 빌드 결과를 제공하는 `http://127.0.0.1:5201/`에서도 태블릿 가로 터치로 96문항과 24활동, 24개 자료 화면, 60개 클립의 실제 전체 재생을 검사했다. 미선택·오답 해설·정답 수정, 출력 신호와 시작 예약 시각, 악보 경계·확대도 통과했다. 개발 소스 모듈이나 정답 주입을 쓰지 않는 검사다.
- 위 전수 빌드 검사는 `quest-CFSe01KN.js`에서 수행했다. 이후 변경은 국악 비교 행의 좌우 여백을 4px에서 2px로 줄인 CSS뿐이다. 최종 빌드 `quest-CXf2Ln7_.js`에서 320·390·768px 비교 행과 음이름·음표 분할·쉼표 실제 화면을 다시 검사하고 캡처했다. 두 행의 가로 넘침과 줄바꿈은 없었다.
- JavaScript 예외는 관측되지 않았다. 단원·보기 변경 후 다시 생성한 JSON과 교사용 Markdown이 소스와 일치한다.

증거는 Git에서 제외한 `output/note-knights/learning-120/` 아래에 있다.

- `quality-pass/bank-browser-report.json`: 전 문항 개발 브라우저 검사, 소리 렌더링·실시간 신호·배치·좁은 화면 비교 행.
- `quality-pass/picture-quality.json` 및 PNG: 최종 빌드의 국악 비교 행과 주요 악보 화면.
- `production-audit/quality-local/report.json`: 로컬 빌드의 태블릿 전수 검사. 폴더 이름과 달리 공개 배포본 검사 결과가 아니다. 보고서의 `base`를 확인한다.

## 남은 검증

PC Chrome의 터치 에뮬레이션이지 실물 iPad/Android 검사가 아니다. Windows WebKit의 오디오 API 미지원 한계도 이전 검사와 동일하게 남는다. 자동 신호 검사는 무음·시점 오류를 잡지만, 사람이 느끼는 음색의 자연스러움이나 초등학생의 읽기 부담·난이도를 보증하지 않는다.

교사 내용 감수와 소규모 학생 수업에서 문항별 정답률·오답 분포·소요 시간·소리 재청취 횟수를 수집해야 한다. 현재는 그런 실측 자료가 없으므로 난이도나 변별도가 검증됐다고 표현하지 않는다.
