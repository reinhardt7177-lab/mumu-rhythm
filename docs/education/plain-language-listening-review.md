# 듣기 문항 쉬운 말 검토

검토일: 2026-11-11

## 범위와 원칙

- 듣기 문항 40개(3~4학년 20개, 5~6학년 20개)의 질문, 선택지 3개, 해설, 선택지별 피드백 3개, 소리 표시 이름을 각각 읽었다.
- 37개 문항의 문구를 수정하고 3개는 유지했다. 아래 표의 '유지'도 전체 문구를 검토한 결과다.
- 모든 소리 표시 이름은 기존의 중립적인 `소리 A`, `소리 B`, `소리 C`, `소리 D`를 유지했다. 악기 이름이나 정답을 표시 이름에 넣지 않았다.
- ID, 학년, 단원, 정답 위치, 소리 ID, 악기, BPM, 음높이, 시작 박, 길이, 세기, 모든 오디오 배열과 이벤트 속성, 악보 음표 구조는 바꾸지 않았다.
- 선택지는 의미와 순서를 유지했다. 바꾼 것은 `listen-34-melody-2`, `listen-34-form-1`, `listen-56-rest-2`, `listen-56-harmony-1`의 표현뿐이다. 나머지 36개는 선택지 원문을 유지했다.
- 4분음표 한 박, 같은 음표 길이 비율, 기기 소리 크기 고정, 다장조, 같은 음높이와 리듬 등 판단에 필요한 음악 조건을 보존했다.
- 준비박은 처음 나올 때 바로 뜻을 풀었다. 낮은 소리 네 번을 한 박씩 끝까지 센 뒤 높은 가락을 같은 빠르기로 세도록 했다. 특히 첫 박 쉼과 둘째 박 뒤쪽 반 박의 시작을 구분하는 조건을 보존했다.
- 평가 대상인 옥타브, 차례가기, 도약, 셈여림, 목관악기, 금관악기, 현악기, 화음은 없애지 않았다. 주변의 어려운 말은 풀고, 필요한 용어는 해설에서 구체적인 소리와 연결했다.
- 질문은 들어야 할 대상과 행동만 알려 준다. 실제로 들리는 악기 이름, 정답 박의 위치, 가락의 방향은 질문에 추가하지 않았다.

## 남은 확인

- 아동 대상 읽기·이해도 관찰은 하지 않았다. 준비박 문항은 정확한 세기 조건을 지키느라 다른 질문보다 길다.
- 이번 검토는 문구와 데이터 보존, 집중 테스트 범위다. 브라우저 줄바꿈·화면 배치와 실제 스피커 재생은 확인하지 않았다.
- 기존 단일 악기 소리 자료의 이조에 따른 음색·잔향 차이, 기기별 들리는 세기 차이는 별도 청취 검증이 필요하다. 이번 수정에서 음원이나 이벤트를 바꾸지 않았다.
- 전체 120개 통합본과 내보내기 파일 갱신은 담당 범위 밖이므로 수정하지 않았다. 커밋·푸시·배포도 하지 않았다.
